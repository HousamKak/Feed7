# Current revision status

The local development site defaults to the native world assembly. `blockforge/world/` holds the authored modules and design data. The current world has 298 entities and 183 compiled mesh assets, with native compiler validation passing. The crystal logo has a closed manifold, diagonal front facets and the original ivory color. The floor channels are modeled recesses with native distance UVs and moving light packets. The browser animates these native assets and a procedural emerald atmosphere. The engine save is `artifacts/native/feed7-native.save.json`. Final photoreal Cycles delivery of this rebuilt scene remains pending. The native studio has been published to GitHub Pages through Actions.

The opening appears before the studio finishes loading. The large world is delivered as an immutable compressed payload, parsed in a worker; a small bootstrap provides the logo, camera route and lighting. The download shrank from approximately 30.8 MB to 6.1 MB. A delayed-world browser test verifies that the logo remains visible while the world request is held. Direct physical rendering fixed the reported black frames. Forward and reverse scrolling, all thirteen chapters, ambient pause and mobile layout have passed browser checks. The opening review also checks smoke, landing, travelling circuit illumination, closing loop and shader errors.

The current source has thirteen stops: supplied-logo opening, circuit-road transition, studio assembly, nine studio views, and a logo closing loop. The central 7 is retained, studio copy alternates sides, and information panels use forest-green glass.

The thirteen-stop Pages browser QA passed before the latest minor logo-lighting and seating refinements. It checked generated assets, ambient motion and pause, loop restart, glass-panel blur, WhatsApp handoff, mobile navigation, and missing resources/runtime errors. All eight API tests passed for the thirteen-stop content structure.

The Blockforge material library and HDRI are used in the interactive renderer. A separate offline Cycles reference has now been rendered: `assets/render-studies/recording-cycles.png`, 1280 by 800, 128 samples, denoised, 9.6 seconds render time. It appears in the in-house work gallery. This is an offline lighting reference, and does not turn the live renderer into a path tracer. Simplified models remain a visible limitation. Native `studio/` files and `docs/live-verification.json` describe the previously verified nine-stop release. They are historical evidence, not verification of the current visual revision.
